# LidGuard

LidGuard — небольшая нативная утилита для macOS, которая переключает поведение сна через `pmset`.
Приложение даёт простой графический интерфейс для включения и выключения `SleepDisabled` при закрытой крышке.

## Зачем нужен проект

`pmset` — мощный инструмент, но для многих пользователей он неудобен из-за работы только через терминал.
LidGuard оборачивает небольшой и понятный набор команд `pmset` в минималистичный интерфейс AppKit.

## Возможности

- Включение в один клик: `pmset -a disablesleep 1`
- Выключение в один клик: `pmset -a disablesleep 0`
- Чтение и отображение текущего состояния `SleepDisabled`
- Использование штатного запроса прав администратора macOS (AppleScript + окно авторизации)
- Без фоновых демонов, телеметрии и сетевых запросов

## Требования

- macOS 13 или новее
- Swift 6.1 или новее (для локальной сборки)
- Права администратора для применения изменений

## Быстрый запуск

```bash
swift build --product LidGuardGUI --configuration release --disable-sandbox
./.build/release/LidGuardGUI
```

## Сборка DMG

Локально:

```bash
./scripts/build_dmg.sh
```

Готовый файл появится в `dist/LidGuard.dmg`.

На GitHub:

1. Откройте вкладку **Actions**.
2. Выберите workflow **Build DMG**.
3. Нажмите **Run workflow**.
4. После завершения скачайте artifact **LidGuard-dmg**.

Workflow также запускается автоматически для тегов вида `v*`, например `v0.1.0`.

## Как это работает

LidGuard выполняет только три команды:

- `pmset -a disablesleep 1`
- `pmset -a disablesleep 0`
- `pmset -g` (чтение текущего значения)

Если `pmset` завершается с ошибкой или пользователь отклоняет авторизацию, приложение показывает текст ошибки.

## Важные замечания

- Приложение меняет глобальные настройки энергопитания. Используйте аккуратно.
- На управляемых/корпоративных устройствах `pmset` может быть ограничен политиками.
- Если настройка не применяется, проверьте значение в терминале:

```bash
pmset -g | awk '/SleepDisabled/ { print $2 }'
```
